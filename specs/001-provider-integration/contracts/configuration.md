# Configuration Contract

## Process startup YAML

The existing process configuration accepts a top-level `providers` sequence:

```yaml
listen_address: 127.0.0.1:8080
log_format: json

providers:
  - name: deepseek
    api_key: ${DEEPSEEK_API_KEY}
  - name: minimax
    api_key: ${MINIMAX_API_KEY}
```

Contract:

- Only `deepseek` and `minimax` are supported.
- Provider names are unique.
- `api_key` is required after `${ENV_VAR}` expansion.
- Provider declarations accept only `name` and `api_key`. The DeepSeek factory relies on the native connector's official default endpoint; the MiniMax factory fixes its OpenAI-compatible endpoint internally.
- Unknown or duplicate YAML keys (including `base_url`), unsupported Providers, and unresolved environment variables fail process configuration loading.
- Errors may identify a field, environment variable, and Provider name, but must not contain expanded secrets.

This file is a process input and is not generated by `oryxos init`.

## Profile YAML

```yaml
name: ops-agent
description: Operations assistant

identity:
  agent_name: Oryx Ops
  prompt: You are a careful operations assistant.

provider:
  name: minimax
  model: MiniMax-M2.7
  temperature: 0.7

tools: []
skills: []
mcp_servers: []
notify_channels: []
schedules: []
channels:
  - name: cli
    config: {}
bootstrap:
  - AGENTS.md
  - SOUL.md
  - USER.md
settings:
  max_iterations: 10
  max_history_turns: 20
```

Contract:

- `name`, `provider.name`, and `provider.model` are required.
- `provider.name` must match a declared process Provider.
- `provider.temperature` defaults to `0.7`, must be finite, and is passed to the selected connector; Provider-specific API rejection is returned without fallback.
- `provider.api_key` and `provider.base_url` are unknown Profile fields and therefore rejected.
- Profile files are independent failure boundaries. Invalid files are reported and skipped; valid files remain registered.
- Duplicate Profile names do not overwrite an existing registration.

The default Profile generated by `oryxos init` must follow this credential-free Provider shape while preserving the fixed six-file workspace contract.
