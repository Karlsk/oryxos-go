### OryxOS
- 定义：基于 Go 1.26 实现的面向企业场景的 Agent OS，部署在企业自有 K8s 或服务器上，作为统一底座承载多个业务 Agent，共享渠道接入、模型路由、工具调用、记忆系统与沙箱执行能力。交付分两段：核心阶段实现运行时内核，扩展阶段补齐多租户、SSO、完整审计等企业级治理能力。

### Agent
- 定义：一个具象的业务智能体，由 Skill 定义做什么、由 Profile 绑定怎么跑。Skill + Profile 绑定后才构成完整可用的业务 Agent，不是写代码写出来的实体。
- 别名：智能体

### Profile
- 定义：Agent 的运行时宿主配置，用 YAML 描述决定 Agent 绑定的 LLM Provider、可用 Tool 列表、Channel、Skill、定时规则等。没有绑定任何 Skill 的 Profile 只是通用助手骨架，不是业务 Agent。
- 别名：配置

### Provider
- 定义：LLM API 服务的抽象，实现统一接口让 Agent 不感知具体调的是哪家模型。核心阶段以 Eino core 的 model.ToolCallingChatModel 为统一接口，具体实现来自 Eino-ext connector。
- 别名：供应商

### ReAct 循环
- 定义：Agent 的核心工作机制（Reason + Act）：LLM 思考是否调用工具，调用后看结果再决定下一步，直到给出最终响应或达到最大迭代次数。核心阶段自研实现，不依赖 Eino ADK Agent 封装。

### Tool
- 定义：Agent 可以调用的外部能力。内置 Tool 是 OryxOS 自带的文件/Shell/HTTP/通知等基础能力；Plugin Tool 是业务方通过 SKILL.md + MCP 零代码扩展、自建 MCP server 轻代码扩展、或实现 Go Tool 接口重代码扩展的能力。
- 别名：工具

### Memory
- 定义：Agent 跨对话保留的状态，分三层：会话记忆（当前对话历史）、长期记忆（.oryxos/memory/MEMORY.md 文件）、情景记忆（扩展阶段）。核心阶段实现前两层，长期记忆通过 save_memory 追加、recall_memory 关键词检索。
- 别名：记忆

### Channel
- 定义：Agent 对外接入的消息入口，负责消息进来、响应出去。核心阶段仅内置 CLI Channel；企业微信、飞书、钉钉、Slack 等 IM Channel 属于扩展功能。HTTP 接入归 Web Service，不属于 Channel。
- 别名：渠道

### Web Service
- 定义：OryxOS 对外暴露的完整 REST API，是业务系统集成 OryxOS 的唯一通道。核心阶段基于 Gin 实现 10 个关键端点，覆盖会话管理、Agent 调用、Profile/Memory/Tool 信息查询与系统状态。

### Session
- 定义：用户和 Agent 一次对话的上下文容器，包含对话历史、当前上下文、临时变量。标识由 Channel + user_id + Profile name 联合生成；核心阶段持久化到本地 SQLite，重启后可恢复。
- 别名：会话

### AgentService
- 定义：CLI、Web Service、定时任务三种触发源共用的 Agent 调用入口，负责调用 ReAct 循环并持久化 Session。同一个 Agent 不因触发源不同而走不同业务链路。

### AgentScheduler
- 定义：定时任务触发模块，按 Profile 的 cron 配置到点生成消息并通过 AgentService 调用 Agent。它是第三种触发源，不是独立的 Agent 执行引擎。

### Sandbox
- 定义：工具执行的隔离环境。核心阶段是应用层白名单校验（文件路径、命令、URL），扩展阶段补容器级隔离（Docker/K8s/WASM）。
- 别名：沙箱

### Tool Policy
- 定义：控制 Agent 可用工具的允许或拒绝规则，在 Profile 级别配置。属于扩展阶段的 Agent OS 治理能力。
- 别名：工具策略

### Skill
- 定义：Agent 的定义本体——这个业务 Agent 该做什么，用 SKILL.md 文件描述（frontmatter 加任务说明正文），兼容 agentskills.io 开放标准。业务方定义新 Agent 写的就是一份 Skill。
- 别名：技能

### Bootstrap
- 定义：加载到系统提示词中的上下文文件：AGENTS.md（项目级 agent 行为说明）、SOUL.md（agent 人格定义）、USER.md（用户偏好）。默认全部加载，显式配置时只加载列出的文件。
- 别名：引导文件

### Workspace
- 定义：OryxOS 实例的工作目录，默认是 .oryxos/，包含 profiles、sessions、skills、logs、memory、mcp_servers.yaml、AGENTS.md、SOUL.md、USER.md 等子目录与文件。
- 别名：工作区
