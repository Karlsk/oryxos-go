本模块由 internal/runtime、internal/scheduler、internal/session、internal/profile 四个空包组成，每个包仅含一个 doc.go，通过注释声明其职责边界：runtime 负责 Agent 运行与 ReAct 循环；scheduler 负责 Profile 定时触发；session 负责会话解析与持久化协调；profile 负责 Profile 加载与运行时注册。这些包遵循项目依赖方向 cmd -> app -> handler/channel/scheduler -> service/runtime，当前阶段以占位形式存在，由 oryxos-init Skill 创建并等待后续 feature specification 填充实现，从而保证编译期包结构稳定、避免后续重构破坏上层引用。
