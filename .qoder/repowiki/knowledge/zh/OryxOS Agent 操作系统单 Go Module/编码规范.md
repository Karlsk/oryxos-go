- 依赖方向严格遵循 cmd → app → handler/channel/scheduler → service/runtime → Eino core interfaces + domain ports，禁止反向导入
- 核心模块边界隔离：runtime 不得导入 Gin、Cobra、GORM 或 Eino-ext；web 不得直接访问 Provider connector 或 Store 实现
- Agent 组成公式统一为 Profile（怎么运行）+ Skill（做什么），Session 身份由 channel + user_id + profile.name 构成
- stateless invoke 固定 channel='http_invoke' + user_id=request_id，scheduler 固定 channel='scheduler' + user_id=schedule.id
- Tool 体系按三档划分：零代码（SKILL.md + MCP）、轻代码（自建 MCP server）、重代码（Go Tool 接口实现），对应 internal_tool 的 tool/builtin/mcp 子包
- Sandbox 作为统一应用层校验层仅提供路径规范化、白名单、超时与输入输出大小限制，不实现容器级强隔离
- 核心链路保持同步执行、Tool 串行调用，不在当前阶段引入复杂异步编排；配置变更通过重启生效，不实现文件监听或热重载
