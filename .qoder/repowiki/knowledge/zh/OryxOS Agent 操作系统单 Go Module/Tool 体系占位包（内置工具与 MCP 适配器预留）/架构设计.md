本模块是 Tool 体系的编译期占位层，当前仅包含三个空包：顶层 `tool` 声明 Tool 注册与执行边界；`builtin` 用于存放零代码/轻代码场景下的内置 Go Tool 实现；`mcp` 用于封装官方 MCP Go SDK 客户端适配器，支撑轻代码 MCP Server 模式。依赖方向遵循 cmd -> app -> handler/channel/scheduler -> service/runtime -> Eino core interfaces + domain ports，本模块作为 runtime 下游的扩展点，不反向依赖上层框架。各子包由 oryxos-init Skill 生成并标记为 compile-safe placeholder，待后续 feature specification 填充具体实现。
