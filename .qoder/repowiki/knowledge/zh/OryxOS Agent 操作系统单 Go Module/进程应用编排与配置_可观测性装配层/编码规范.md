- 对外暴露的入口函数采用 Options struct 模式（如 FoundationOptions）并通过 nil 检查注入默认行为，便于测试注入替换。
- 配置加载统一走 LoadServerYAML → decodeSingleDocument → rejectDuplicateKeys → expandScalars → validateYAMLShape → strictDecode → validateServerConfig 的固定流水线，错误通过 configError 携带路径信息。
- 组件生命周期遵循 Start(context) 阻塞至就绪、Close(context) 尊重超时、可选实现 TerminalSource.Errors() 上报终端错误的三件套契约。
- slog 日志一律经 RedactingHandler 包装，对敏感键、error/error_* 字段及 URL 字符串自动脱敏后再写入下游 Handler。
- 可观测数据通过 Observer 接口聚合并在 Snapshot 中拷贝后排序返回，避免外部直接持有可变状态。
