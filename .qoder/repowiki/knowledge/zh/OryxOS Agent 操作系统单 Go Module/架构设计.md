根模块 `github.com/Karlsk/oryxos-go` 通过 `cmd_oryxos` 作为唯一可执行入口，按作者约定的严格依赖方向 `cmd -> app -> handler/channel/scheduler -> service/runtime -> Eino core interfaces + domain ports` 组织子包：`internal_core` 编排进程生命周期并加载 YAML 配置；`internal_runtime` 提供 runtime/scheduler/session/profile 四个核心骨架；`internal_agent` 与 `internal_tool` 分别预留 memory/provider/skill/channel/cli 及 tool/builtin/mcp 三类扩展点；`internal_web` 基于 Gin 暴露健康检查与信息接口并通过统一响应信封对外输出；`docs` 维护需求、方案与 superpowers specs。各子模块之间仅通过内部包名引用，禁止跨层反向导入（如 runtime 不得引入 Gin/Cobra/GORM/Eino-ext，web 不得直接访问 Provider connector/Store），从而保证边界清晰、可独立编译验证。
