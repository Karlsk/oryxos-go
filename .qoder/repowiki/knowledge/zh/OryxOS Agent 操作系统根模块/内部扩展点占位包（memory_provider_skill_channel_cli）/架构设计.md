本模块由四个独立的 internal 子包组成，每个子包仅包含一个 doc.go 占位文件，通过空 package 声明保证依赖方编译通过，同时明确各扩展点的职责边界：memory 负责 Markdown 驱动的长期记忆存储；provider 负责模型提供商工厂与适配器；skill 负责加载 Profile 引用的 SKILL.md 内容；channel/cli 负责核心阶段的命令行消息通道。这些包遵循项目依赖方向 cmd -> app -> handler/channel/scheduler -> service/runtime -> Eino core interfaces + domain ports，当前阶段作为 compile-safe placeholder 被上层预留引用，实际行为由后续 feature specification 逐步实现。
