模块由四个相互协作的子包构成，依赖方向为 app → observability/config，config 与 observability 之间无循环：
- internal/app：定义 Component/SignalContextFactory/TerminalSource 接口，Application 按注册顺序调用 Start，任一组件通过 Errors() 通道上报终端错误即触发反向 Close；Run 使用 reflect.Select 同时监听 root context 与各组件错误通道，shutdown 阶段用 sync.Once 保证幂等并以超时关闭所有已启动组件；FoundationOptions 通过注入 LookupEnv/ListenerFactory/SignalContextFactory 暴露测试钩子。
- internal/bootstrap：当前仅为占位包（doc.go），由 oryxos-init Skill 生成，预留后续扩展 Bootstrap prompt-context 加载逻辑。
- internal/config：以 yaml.Node 为中间表示，LoadServerYAML 依次执行单文档校验→去重→变量展开→形状校验→严格解码→默认值填充→字段验证，返回强类型 ServerConfig；通过 *string + KnownFields(true) 实现未知字段报错，并支持 ${ENV} 形式的标量展开；错误统一包装为 configError 携带路径信息。
- internal/observability：Observer 接口封装 HTTP 请求聚合与就绪标志，内部 observer 使用 RWMutex 维护 map[httpRequestKey]HTTPRequestSnapshot；日志通过 slog.Handler 链 NewConsoleHandler/NewJSONHandler → RedactingHandler 包装，对敏感键、error/error_* 字段及 URL 字符串进行脱敏输出。
边界约定：runtime 不直接依赖 Gin/Cobra/GORM/Eino-ext，web 不直接访问 Provider connector/Store 实现，本模块仅依赖标准库与 gopkg.in/yaml.v3。
