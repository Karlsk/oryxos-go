- 所有 API 响应统一包裹在 `Result[T]` 信封中，HTTP 状态码表达传输语义，稳定小写 snake_case 的 `code` 字段表达应用分类，客户端不得依据 message 文本分支。
- `X-Request-ID` 请求头透传：存在则复用，不存在则由中间件生成，响应头、body `request_id` 与访问日志关联值必须字节级一致。
- 公共 JSON 一律使用 snake_case，时间戳统一以 RFC3339 UTC 字符串输出，禁止暴露本地时区偏移或 Unix 时间戳。
- 分页采用 PageResult[T]，page/page_size 默认 1/20，取值范围 page 1..10000、page_size 1..100，空页 items 序列化为 `[]` 而非 null。
- 错误 details 仅允许包含 field/rule 两个字符串键，非法描述符、页参数或 details 统一回退到 `500/internal server error` 且不带 data/details。
- 敏感信息（请求体、头部、查询值、数据库错误、文件路径、堆栈、凭证、token、webhook URL、展开配置）一律不在响应中返回。
